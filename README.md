# Captain Claw — Full HTML Build

This repository is dedicated to building the real `pjasicek/OpenClaw` C++ engine into WebAssembly and packaging the official OpenClaw v1.03 game resources into a standalone browser build.

- Engine source: `pjasicek/OpenClaw`
- Game data: official OpenClaw v1.03 release (`CLAW.REZ`, `ASSETS.ZIP`, font/config resources)
- Target: one giant mobile/desktop HTML file using the real OpenClaw engine and original game assets

Build work is isolated in this repository so unrelated projects are not modified.
